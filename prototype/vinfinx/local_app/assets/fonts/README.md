# Bundled typography

Nunito variable font (weights 200–1000), unmodified, distributed under SIL OFL 1.1.
The full license and copyright notice are in `OFL.txt` beside the font.

Source: https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/nunito

The browser loads this file from the app itself, not a font CDN. Main headings,
body text, controls and the phone shell use the same font on all platforms.
Native select controls, emoji, rasterization and print output may still vary by OS.
